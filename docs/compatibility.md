# Kompatybilność

| Środowisko | Cel | Status |
| --- | --- | --- |
| Python 3.11+ | Podstawowe algorytmy offline | NOT_RUN |
| Windows / Linux | Klient i testy syntetyczne | NOT_RUN |
| OpenCV / NumPy / SciPy | Potencjalne adaptery/numerics | NOT_RUN |
| ROS2 | Wymiana obserwacji przez konsumenta | NOT_RUN |
| Unity / Unreal | Eksperymenty XR i awatary | NOT_RUN |
| Rzeczywiste kamery / roboty | Tracking na hostach docelowych | NOT_RUN |

Nie deklarować wsparcia hardware ani SDK bez testu z jawną wersją, SHA i źródłem danych.
