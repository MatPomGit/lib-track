ADR zapisują uzasadnienie decyzji, alternatywy i konsekwencje; nie zastępują kodu ani testów. Każdy nowy ADR zawiera datę, status `proposed/accepted/rejected/superseded`, kontekst, decyzję, alternatywy, konsekwencje, dowody i odnośniki. `proposed` nie upoważnia do wdrożenia. Zmiana zaakceptowanej decyzji wymaga nowego ADR z odnośnikiem do zastępowanego i zachowaniem historii (status `superseded`).

[Standard dokumentacji i limity](../documentation.md) oraz [zasady agentów](../../AGENTS.md) obowiązują także ADR. ADR określa zakres projektowy, nie potwierdza działania kodu ani wydania.
