# motion

Predykcja stanu i filtrowanie trajektorii.

Predykcja ruchu jest oddzielona od obserwacji. Filtr musi podawać zastosowany model dynamiki, procesową i pomiarową macierz kowariancji, krok czasu i warunki inicjalizacji. Przeskok czasu, odwrócona chronologia i osobliwe macierze skutkują jawnym błędem lub statusem degradacji.

**Status: PLANNED / NOT_IMPLEMENTED.** [Planowany kontrakt](../../../docs/contracts.md) i [walidacja](../../../docs/testing.md).
