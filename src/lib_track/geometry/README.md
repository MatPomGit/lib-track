# geometry

Transformacje współrzędnych i fuzja źródeł.

Pozycje 2D i 3D nie mogą być mieszane bez jawnej projekcji/transformacji. Metadane zawierają `frame_id`, jednostkę (px/m), model kamery, transformację i jej wersję/kalibrację. Integracje z TF2 i silnikami 3D należą do adapterów w konsumentach.

**Status: PLANNED / NOT_IMPLEMENTED.** [Planowany kontrakt](../../../docs/contracts.md) i [walidacja](../../../docs/testing.md).
