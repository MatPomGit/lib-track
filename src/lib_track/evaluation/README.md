# evaluation

Ewaluacja jakości śledzenia.

Do planu testów należą metryki detekcji i wieloobiektowego trackingu: precision/recall, IoU, liczba zmian identyfikatorów, IDF1, MOTA i HOTA. Każda metryka wymaga opisanej definicji, benchmarku, sposobu dopasowania GT i tolerancji czasu. Nie raportować metryk jako wykonanych bez wyników.

**Status: PLANNED / NOT_IMPLEMENTED.** [Planowany kontrakt](../../../docs/contracts.md) i [walidacja](../../../docs/testing.md).
