# detections

Normalizacja detekcji 2D/3D, punktów kluczowych i pomiarów.

Detekcje mogą mieć postać prostokątów 2D, punktów kluczowych, masek, wektorów 3D i pomiarów z innych sensorów. Wynik detektora musi zawierać rozdzielczość lub jednostki geometryczne, a confidence musi pozostać jawnie opcjonalne. Moduł nie uruchamia żadnego modelu detekcyjnego.

**Status: PLANNED / NOT_IMPLEMENTED.** [Planowany kontrakt](../../../docs/contracts.md) i [walidacja](../../../docs/testing.md).
